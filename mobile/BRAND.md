# Device Management Brand

Source: the user's latest approved white-background / black-CTA direction supplied on 12 October 2026. This replaces the dark Soun theme and pale peach introduction.

- White canvas: #FFFFFF
- Neutral grouped surfaces: #F6F6F7 and #EDEDEF
- Main text: #111111
- Secondary text: #626268
- Primary actions: #000000
- Supporting team accents: magenta #9A257B and orange #B64221
- Primary button text: #FFFFFF
- Typography: bundled Google Sans regular, medium, semibold and bold.

The spectrum is retained only in reflective glass imagery and restrained team identification. Important actions use black with white labels. Native navigation, picker hosts, segmented controls, status bars, and system appearance all use the light scheme. The source logo and audio playback controls are not copied into the device-management product.

The opening shows a fully contained, gently bobbing reflective bubble and the swipe prompt. An upward swipe reveals 20 local employee-photo bubbles, the approved copy, and a black Continue with work email button. No work-email CTA appears during the opening. The CTA opens a work-email entry screen. Real identity-provider verification is not configured; the screen reports this honestly and never treats entering an email as authentication or silently opens the register.

Platform behavior: native iOS large title on the register, native stack transitions and edge-swipe back, modal Cancel actions, system confirmation dialogs, grouped specification/form rows and a full-height virtualized inventory. Every child screen also has an All devices toolbar action. Scan/registration/link completion restores a Devices -> Details stack.

Saved records and the storage key are preserved. New registration is a persistent full-width primary action on the unmatched-scan screen. Search and filters show their active state and can be cleared.

This machine has no configured simulator; physical-device screenshot verification remains outstanding. Type checking, real stack-router regression tests, inventory filtering tests and native bundle exports verify code behavior, not visual fidelity.
